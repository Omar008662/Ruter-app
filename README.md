# 🚍 Brukerveiledning

Dette prosjektet er en Ruter-inspirert nettside som jeg har utviklet selv. På nettsiden kan du søke etter holdeplasser, se sanntidsavganger for kollektivtransport, utforske et kart over området rundt deg og lagre favorittstopp for rask tilgang senere.

## 🔎 Slik bruker du nettsiden

1. Trykk på søkefeltet på startsiden.
2. Skriv inn navnet på holdeplassen du ønsker å reise fra.
3. Trykk på **Søk**-knappen.

Du blir deretter sendt til en side som viser kollektivtransport fra den valgte holdeplassen, inkludert buss, trikk, tog og T-bane med sanntidsinformasjon om neste avganger.

## ⭐ Favorittstopp

Hvis du ofte bruker de samme holdeplassene, kan du legge dem til som favoritter.

1. Søk opp en holdeplass.
2. Trykk på knappen for å legge holdeplassen til som favoritt.
3. Holdeplassen lagres i databasen og kan vises på favorittsiden.

Dette gjør det raskere å finne avganger fra holdeplasser du bruker ofte.

## 🗺️ Kartfunksjon

Øverst til høyre finner du en knapp som heter **Kart**.

Når du trykker på den, blir du sendt til en side som viser et kart over området rundt deg. Kartet kan brukes til å få oversikt over nærliggende holdeplasser og området du befinner deg i.

## 🏠 Tilbake til hjemmesiden

Hvis du ønsker å gå tilbake til startsiden, kan du når som helst trykke på **Ruter#**-logoen.

## ⚙️ Teknologi brukt

Dette prosjektet er utviklet med følgende teknologier:

* 🐍 Flask – backend og routing
* 🗄️ MariaDB – lagring av favorittstopp
* 🌐 HTML – struktur på nettsidene
* 🎨 CSS – design og utseende
* 🚏 Ruter API – henting av sanntidsdata for kollektivtransport
